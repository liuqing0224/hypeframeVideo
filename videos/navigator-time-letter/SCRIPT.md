# Manga Performance Script

## 01-start - 航海图开门

- [narration/narrator] 旁白：子墨穿过发光墨迹，来到明代古港。
- [dialogue/primary] 子墨：这里真是六百年前的港口？
- [dialogue/secondary] 郑和：少年，你从何处而来？

## 02-middle - 重建航线

- [narration/narrator] 旁白：海风吹散了航海图上的路线标记。
- [dialogue/primary] 子墨：可以用星位和季风重新确认方向。
- [dialogue/secondary] 郑和：好，我们一起把航线找回来。

## 03-end - 写给未来

- [narration/narrator] 旁白：郑和把写给未来少年的信交给子墨。
- [dialogue/secondary] 郑和：愿你永远保有探索世界的勇气。
- [dialogue/primary] 子墨：我会把这封信带回未来。
