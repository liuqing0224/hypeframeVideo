# Manga Performance Script

## 01-start - 微弱星种

- [narration/narrator] 旁白：失去星光的森林里，小鹿带来一颗星种。
- [dialogue/primary] 叶芽：别怕，我会保护这颗星种。
- [dialogue/secondary] 小鹿：最高的古树还在等它。

## 02-middle - 风雨护送

- [narration/narrator] 旁白：叶芽和小鹿顶着风雨穿过森林。
- [dialogue/primary] 叶芽：风雨再大，也不能让星种熄灭。
- [dialogue/secondary] 小鹿：跟紧我，我们越过前面的断木！

## 03-end - 星花盛开

- [narration/narrator] 旁白：星种在古树顶端开成漫天星花。
- [dialogue/primary] 叶芽：我们做到了，森林重新亮起来了！
- [dialogue/tertiary] 猫头鹰：星花开满天空啦！
