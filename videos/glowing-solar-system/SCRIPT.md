# Manga Performance Script

## 01-start - 熄灭的展厅

- [narration/narrator] 旁白：中央太阳系模型正在一颗颗熄灭。
- [dialogue/primary] 小曦：阿朗，你看，行星正在失去亮光！
- [dialogue/tertiary] 小光：能量连接异常，请帮助我修复轨道。

## 02-middle - 追逐能量

- [narration/narrator] 旁白：三人沿着行星轨道寻找能量碎片。
- [dialogue/secondary] 阿朗：先按顺序连接轨道，别接错位置！
- [dialogue/primary] 小曦：我去拿金色碎片，小光负责扫描！

## 03-end - 点亮未知

- [narration/narrator] 旁白：太阳和八颗行星全部重新发光。
- [dialogue/secondary] 阿朗：最后一条轨道接通了！
- [dialogue/tertiary] 小光：好奇心，就是点亮未知的光。
